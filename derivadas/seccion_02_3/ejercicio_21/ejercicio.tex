\item Con referencia al Ejemplo 4, si una molécula del producto C se forma de una molécula del reactivo A y una molécula del reactivo B, y las concentraciones iniciales de A y B tienen un valor común $[A] = [B] = a$ mol/L, entonces $[C] = a^2kt / (akt + 1)$, en donde $k$ es una constante.
\begin{enumerate}
    \item[(a)] Encuentre la velocidad de reacción en el tiempo $t$.
    \item[(b)] Demuestre que si $x = [C]$, entonces
    $$\frac{dx}{dt} = k(a - x)^2$$
\end{enumerate}
