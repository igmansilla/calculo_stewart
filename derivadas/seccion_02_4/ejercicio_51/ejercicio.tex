\item Aplique el proceso de derivación a las siguientes identidades trigonométricas para obtener identidades nuevas (o conocidas).
\begin{enumerate}
    \item[(a)] $\displaystyle \tan x = \frac{\operatorname{sen} x}{\cos x}$
    \item[(b)] $\displaystyle \sec x = \frac{1}{\cos x}$
    \item[(c)] $\displaystyle \operatorname{sen} x + \cos x = \frac{1 + \cot x}{\csc x}$
\end{enumerate}
