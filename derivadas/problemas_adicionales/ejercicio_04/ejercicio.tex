\begin{enumerate}
    \item[(a)] Resuelva la desigualdad $|x + 1| + |x - 2| < 7$.
    \item[(b)] Trace la gráfica de la función $f(x) = |x + 1| + |x - 2|$.

    \item[(e)] Trace la gráfica de $g(x) = |x| + |x + 1| + |x - 1|$.
