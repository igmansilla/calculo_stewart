\item Efectúe los pasos siguientes para demostrar que la sucesión
    \[ t_n = 1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n} - \ln n \]
    tiene límite. (El valor del límite se denota con $\gamma$ y se llama constante de Euler).
    \begin{enumerate}
        \item[(a)] Haga una ilustración como la de la figura 10.8 con $f(x) = 1/x$ e interprete $t_n$ como un área [o use (10.22)] para demostrar que $t_n > 0$ para todo $n$.
        \item[(b)] Interprete
        \[ t_n - t_{n+1} = [\ln(n + 1) - \ln n] - \frac{1}{n + 1} \]
        como una diferencia de áreas para demostrar que $t_n - t_{n+1} > 0$. Por consiguiente $\{t_n\}$ es una sucesión decreciente.
        \item[(c)] Aplique el teorema 10.11 para demostrar que $\{t_n\}$ es convergente.
    \end{enumerate}
