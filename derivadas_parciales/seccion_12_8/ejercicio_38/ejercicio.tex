\item (a) Maximice la función $\sum_{i=1}^n x_i y_i$ sujeta a las restricciones $\sum_{i=1}^n x_i^2 = 1$ y $\sum_{i=1}^n y_i^2 = 1$. \\
(b) Sustituya
\[ x_i = \frac{a_i}{\sqrt{\sum a_i^2}} \qquad \text{y} \qquad y_i = \frac{b_i}{\sqrt{\sum b_i^2}} \]
para demostrar que
\[ \sum a_i b_i \le \sqrt{\sum a_i^2} \sqrt{\sum b_i^2} \]
para números arbitrarios $a_1, \dots, a_n, b_1, \dots, b_n$. Esta se conoce como la desigualdad de Cauchy-Schwarz.
